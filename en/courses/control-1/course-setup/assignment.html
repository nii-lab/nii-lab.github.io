01 The controlled system and goal

Example scenario To maintain a room at a desired temperature, what must you be able to measure and adjust?

Description
  • Specify the measured output, such as temperature, and its target range
  • Identify adjustable inputs, such as heating output

02 Why use computational tools?

How can examining responses on a computer help before changing a physical device?

Description
  • Comparing responses to different control actions using a model can narrow down candidates to test on the actual device.
  • MATLAB supports calculation and visualization. Judge whether results are appropriate using the objective and model assumptions.
