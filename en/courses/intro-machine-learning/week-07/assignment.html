Linear Regression

English translation

Examine predictions outside the observed range and the effect of an outlier on the regression equation.

Before practice

01 Does a small training error guarantee predictions far outside the observed range?

Description

Predictions outside the data range assume unobserved relationships and must be judged separately.

02 How much can one outlier change the slope?

Description

A point with a large residual contributes greatly to squared error and can change the slope and intercept.

2. The Influence of One Sample

Starting conditions

Create data with the last y changed to 18 and compare changes in coefficients, MSE, and predictions at x=6x=6.

Procedure

  1. Keep x unchanged and create a copy with only the last y changed to 18. Apply np.linalg.lstsq separately to the original and modified data.
  2. Record the two models' w,bw,b, MSE on their respective training data, and predictions at x=6x=6 in two rows. Plot the original points, modified points, and both prediction lines on the same axes.
  3. Using the table and plot, explain how changing one sample affected the coefficients and predictions for new inputs.
