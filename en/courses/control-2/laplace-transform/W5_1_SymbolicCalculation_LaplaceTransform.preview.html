Laplace Transform

Declare t and s as symbols for the Laplace transform, and define f

t, s = sym.symbols('t, s')
a = sym.symbols('a', real=True, positive=True)
f = sym.exp(-a*t)
f
exp(-a*t)

Taking the Laplace transform

F = sym.laplace_transform(f, t, s)

⎛  1            ⎞

Suppressing the conditions for existence of the Laplace transform

F = sym.laplace_transform(f, t, s, noconds=True)

Defining a function to simplify Laplace-transform calculations

def L(f):
    return sym.laplace_transform(f, t, s, noconds=True)

def invL(F):
    return sym.inverse_laplace_transform(F, s, t)
