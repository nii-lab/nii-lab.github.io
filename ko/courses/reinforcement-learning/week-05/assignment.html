Policy Gradient와 Actor–Critic

대학원 · 연구 적용 실습

확률적 정책의 직접 갱신을 확인한 뒤 Critic이 긴 Episode의 학습을 어떻게 바꾸는지 살펴봅니다.

실습 전에

01 확률적 정책을 직접 갱신한다는 것은 무엇일까요?

설명

REINFORCE는 선택 행동의 Log Probability를 Return으로 가중합니다. Baseline을 빼도 Reward Function 자체가 바뀌는 것은 아닙니다.

02 Critic이 틀리면 Actor도 영향을 받을까요?

설명

A2C는 Critic으로 미래 가치를 추정하고 Advantage를 계산해 Actor를 갱신합니다. Rollout 길이는 실제 보상과 Bootstrap의 비중을 바꿉니다.

실행 조건

  • 필요 패키지: gymnasium·stable-baselines3·PyTorch.
  • SB3 정책: MlpPolicy.
  • Gymnasium step: 5개 반환값.

필요한 패키지가 없으면 Colab·Jupyter 코드 셀에서 %pip install gymnasium==1.3.0 stable-baselines3==2.9.2를 실행하세요.

진행 방법

시작 조건
