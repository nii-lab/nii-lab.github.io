이번에 배울 내용

좌표 변화에서 이동 거리와 속도를 계산하고, 함수와 그래프로 결과를 확인합니다.

배열 전체를 한 번에 계산하기

.^, .* , ./는 대응하는 원소끼리 계산합니다. *는 행렬곱입니다. 평면 이동의 길이는 sqrt(dx.^2+dy.^2) 또는 hypot(dx,dy)로 구할 수 있습니다.

함수의 입력·출력과 그림

함수 이름만 외우기보다 입력의 크기·단위와 출력의 의미를 먼저 확인합니다. 같은 길이의 시간·측정 배열을 plot에 넣고 축·단위를 표시하면 계산 결과가 실제 변화와 맞는지 볼 수 있습니다.

Onramp와 연결하기

Array Calculations, Calling Functions, Plotting Data의 예제를 체험한 뒤 합성 이동 기록으로 같은 계산을 수행합니다.

풀이 예제

세 이동의 dx=[0.30.40]\mathrm{dx}=\left[\begin{array}{ccc}0.3&0.4&0\end{array}\right] m, dy=[0.400.2]\mathrm{dy}=\left[\begin{array}{ccc}0.4&0&0.2\end{array}\right] m에서 구간 길이와 전체 길이를 구합니다.
dx=[.3;.4;0];dy=[.4;0;.2];
segment_m=hypot(dx,dy);total_m=sum(segment_m);
disp(segment_m);disp(total_m);
assert(max(abs(segment_m-[.5;.4;.2]))<1e-12);
assert(abs(total_m-1.1)<1e-12);
bar(segment_m);xlabel('Segment');ylabel('Distance [m]');grid on;

예제 결과

구간 길이는 .5, .4, .2 m이고 전체 길이는 1.1 m입니다.
